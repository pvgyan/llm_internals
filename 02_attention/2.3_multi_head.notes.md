Q: 多头注意力并不增加总计算量。
---
这个能举具体的例子来说明 MultiHead(Q,K,V)=Concat(head1 ,…,head h )W跟之前的计算量一样吗？

关键前提：**多头不是“把单头复制 h 份”**，而是把 `d_model` 切成 h 份，每份 `d_k = d_model / h`。所以“总宽度”没变，只是换了一种用法。

下面用原论文配置举例：`n = 序列长度 = 4`，`d_model = 512`，`h = 8`，`d_k = d_v = 64`。

---

## 1. 单头注意力（维度 512）

输入：
- Q, K, V: `(n, 512)`

### 投影
```text
Q = X @ W_Q   # W_Q: (512, 512)
K = X @ W_K   # W_K: (512, 512)
V = X @ W_V   # W_V: (512, 512)
```
每个投影乘法次数 ≈
`n * 512 * 512 = 4 * 262144 = 1,048,576`
三个投影：约 `3,145,728`

### 注意力分数
```text
Q @ K^T   # (4,512) @ (512,4) = (4,4)
```
每次点积做 512 次乘法，共 `4*4*512 = 8192`

### 加权求和
```text
A @ V   # (4,4) @ (4,512) = (4,512)
```
也是 `4*4*512 = 8192`

### 输出投影
如果有 `W_O: (512,512)`，再加 `n*512*512 = 1,048,576`

单头总投影参数量/计算量核心项是：
```text
3 * n * d_model^2 + 2 * n^2 * d_model + n * d_model^2
= 4n d_model^2 + 2 n^2 d_model
```

---

## 2. 多头注意力（8 头，每头 64 维）

每个头：
- `W_i^Q, W_i^K, W_i^V`: `(512, 64)`
- head 输出: `(n, 64)`

### 单个头投影
```text
Q_i = X @ W_i^Q   # (4,512) @ (512,64) = (4,64)
```
乘法次数：
`4 * 512 * 64 = 131072`

三个投影：
`3 * 131072 = 393216`

8 个头合计：
`8 * 393216 = 3,145,728`

👉 **和单头里 `3 * n * 512 * 512` 完全一样**，因为：
```text
h * (d_model * d_k)
= 8 * (512 * 64)
= 8 * 32768
= 262144
= 512 * 512
```

也就是：
```text
h * d_model * d_k = d_model * d_model
```

---

## 3. 注意力分数

单头：
```text
(4,512) @ (512,4) -> 4*4*512 = 8192
```

多头每个头：
```text
(4,64) @ (64,4) -> 4*4*64 = 1024
```
8 个头：
```text
8 * 1024 = 8192
```

又因为：
```text
h * n^2 * d_k = n^2 * (h d_k) = n^2 * d_model
```

所以注意力核心计算量也一样。

---

## 4. Concat + W_O

8 个 head 输出拼起来：
```text
concat -> (4, 8*64) = (4, 512)
```

输出投影：
```text
concat @ W_O   # W_O: (512,512)
```
乘法次数：
`4 * 512 * 512 = 1,048,576`

这层和“带输出投影的单头”也一样。

---

## 5. 一句话对账

| 项目 | 单头 512 维 | 8 头 × 64 维 |
|---|---|---|
| Q/K/V 投影 | `3 n 512^2` | `8 × 3 n 512×64` |
| 注意力分数 | `n^2 × 512` | `8 × n^2 × 64` |
| 加权求和 | `n^2 × 512` | `8 × n^2 × 64` |
| 输出投影 | `n 512^2` | `n 512^2` |
| 总计算量 | 一样 | 一样 |

所以书里那句话的意思是：

> 多头注意力不是“多做几倍注意力”，而是把原来 512 维的一次注意力，拆成 8 个 64 维的并行注意力；总乘法次数几乎不变，但模型可以同时看多个子空间。

严格说不是“绝对零开销”：多头会多存 `h` 个 `(n,n)` 注意力矩阵、reshape/transpose 也有一点工程开销。但**主导项 FLOPs 相同**，这就是它被称为“近似免费午餐”的原因。
